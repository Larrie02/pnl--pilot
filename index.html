About PnL Pilot

PnL Pilot helps traders estimate the result of a trade before they place it, or check a trade they have already closed. It turns a few inputs into a clear net profit or loss, a return percentage and a break-even price.

It is built for crypto and memecoin traders, and for beginners learning how trading maths works. It is a simple frontend-only tool. It does not connect to a wallet, execute trades, ask for private keys or seed phrases, or fetch live prices. You type in the numbers and it does the maths.

The formulas and simplifying assumptions are documented in the project README so you can check every result yourself.
